# frontend/features/ —— L5 三面板前端规格（Next.js 15 + TS + antd + Tailwind）
**归属任务**: T-05（本体工作台）/ T-09（决策卡面板）/ T-12（进化看板）/ T-14（资产看板）
**技术栈冻结**（03 计划 §4.1）: `@antv/g6 v5`（本体树/图谱可视化）、`@xyflow/react`（Skill 拓扑）、`recharts`（评测曲线）、`motion`（产品内动画；GSAP 仅限 PPT/视频工程）。路由注册归 T-12 接线。

## 1. knowledgeGraph/（本体工作台，T-05，评分维度3+4 交互主载体）

```
本体工作台
├── 提案队列页: 逐条确认流——每条只展示 [提案+证据锚点原文+影响面摘要+置信度]，
│   操作: 确认/否决/改父类（信息最小化, K1 §3 排序切批 40/会话）
├── 本体树页: G6 树布局, 类节点带 anchor 标记(锚定标准条目), 点击看属性/关系
├── diff 视图: 两版本操作日志回放（added 绿/deprecated 灰/changed 黄）
└── 质量面板: K0 四指标 + 人工基线对照（recharts 雷达图）
```
交互细节：确认动线 ≤3 击（看证据→决策→下一题）；键盘流（A 确认/X 否决/P 改父）支持专家批处理节奏；证据锚点原文悬浮预览（不打断队列）。

## 2. decisionCard/（决策卡面板，T-09，评分维度2 溯源主载体）

```
决策卡面板
├── 卡片主视图: 候选方案×评分×校准置信度; 知识版本戳徽标(可点击)
├── 证据链展开: 命题→EXTRACTED/INFERRED 标签色分→doc/span 溯源跳转(打开原文定位)
│               →kg_path 图谱路径回放(G6 mini 图, 高亮路径)
├── 反事实折叠区: "不选 A 会怎样"(默认折叠)
├── 版本对比模式: 同问题新旧知识戳双卡并排(T-11 演示⑤的 UI)
└── 反馈条: 👍/👎+一句话(K7 采集入口, 一行交互)
```
跳转协议：doc/span 定位用 Nexent 原生知识库引用组件复用（深度集成的证据）；kg_path 回放调 `kg_multi_hop` 的路径数据。

## 3. assetDashboard/（资产看板，T-14，评分维度2 激活叙事）

```
资产看板
├── 资产总览: N 份沉睡文档→M 资产→K 可答决策问题的漏斗(评分维度2 量化叙事)
├── 资产明细: 模态徽标(文本/表格/图文)/权威等级/解析体检分/血缘链(版本族谱)
├── 血缘图: doc_asset supersede_of 族谱(xyflow)
└── 激活动态: 最近被证据引用的资产流(证明"沉睡→激活")
```

## 4. 进化看板（knowledgeGraph/ 内嵌页, T-12）
时间线动画（motion）：`evolution_round_t` 逐轮播放——触发源图标→Δ摘要气泡→评测分变化曲线联动（recharts 同步高亮）。本体 diff 可视化与决策卡面板复用组件。

## 动画纪律
产品内一律 `motion`（MIT）；尊重 `prefers-reduced-motion`；动画时长 200-400ms 缓动；演示视频工程另用 GSAP（不进产品代码，03 计划 §4.3）。

## 验收锚点
- `npm run check-all`（type-check+lint+format+build）过；
- 三面板路由可达（T-12 接线后）；
- 演示关键帧截图集（确认流/证据链展开/版本对比/漏斗）存 `competition/deliverables/`。
