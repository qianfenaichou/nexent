# CONTEXT.md —— KnowEvo 领域术语表

> 全队（含 AI 编码任务）统一语言。术语冲突时以本表为准；新术语在首次出现时补进本表（domain-modeling 纪律：glossary only，无实现细节）。

## 知识层

| 术语 | 定义 | 反义/易混 |
|---|---|---|
| **本体（Ontology）** | 领域概念的骨架：类+属性+关系类型+继承偏序。版本化于 `ontology_version_t` | ≠图谱：本体是 schema，图谱是实例 |
| **类（Class）** | 本体中的概念节点（如 `Drug`）。带 `stable_id`（跨版本不变）与 `anchor`（标准文档锚点） | ≠实体：类是类型，实体是个体 |
| **图谱（KG）** | 按 active 本体锚定的实体+关系实例网络，bi-temporal | ≠知识库（Nexent 原生的文档检索库） |
| **实体（Entity）** | 图谱节点个体（"二甲双胍"这个药，不是 `Drug` 类）。`stable_id` 域内稳定 | — |
| **关系/边（Relation/Edge）** | 实体间带命题文本（claim）的连接，双时间戳 | — |
| **证据（Evidence）** | 溯源最小单元：文档内一段原文/表格单元格 + 引用它的实体/边。`EXTRACTED`=原文明述，`INFERRED`=推断 | — |
| **待审池（Pending Pool）** | 无法映射到本体的实体暂存区，高频者触发新类提案 | — |
| **知识版本戳（Knowledge Stamp）** | 决策卡引用的知识定位：`{ontology_version, kg_cutoff}`。与 Nexent Agent 版本解耦 | ≠Agent 版本 |

## 时间与演化

| 术语 | 定义 |
|---|---|
| **valid_at / invalid_at** | 事实有效时间轴：该事实在现实世界中何时为真/失效（指南发布日口径） |
| **retrieved_at / superseded_at** | 系统认知时间轴：我们何时入库/何时被新记录覆盖 |
| **现行视图（Valid View）** | 查询默认口径：`valid_at ≤ now AND (invalid_at IS NULL or > now)` |
| **受控失效（Supersede）** | 新事实取代旧事实时给旧边打 `invalid_at` 戳，**不物理删除** |
| **进化轮（Evolution Round）** | 一次知识变更事件的完整记账：触发源→操作摘要→成本→评测变化 |
| **进化 ROI** | Δ质量（pp）与成本的并列报告（不做比值主指标，备忘录裁决 9） |

## 决策层

| 术语 | 定义 |
|---|---|
| **决策卡（Decision Card）** | 决策输出载体：候选方案×证据链×置信度×风险×反事实×知识版本戳。医疗场景附认知辅助免责声明 |
| **证据链（Evidence Chain）** | 命题级溯源列表：claim → {doc, span, kg_path, tag} |
| **双驱动（Dual-Drive）** | 检索路（R：doc_search+kg_search）与推理路（M：kg_multi_hop 束搜索）协同；路由器分派 R/M/RM |
| **路由器（Router）** | 规则前置+小模型 few-shot 分类的三路分派器；不确定默认双路 RM |
| **多跳（Multi-hop）** | 图谱上 ≤3 跳、束宽 3 的束搜索推理 |
| **版本敏感题（V 题）** | 同一问题在两版指南下答案不同的测试题，双金标 `answer_old/answer_new` |

## 流程层

| 术语 | 定义 |
|---|---|
| **提案（Proposal）** | 本体变更候选（类/属性/关系级），带证据锚点+置信度，走确认环 |
| **确认环（Confirm Loop）** | 专家对提案队列逐条 确认/否决/改父类 的轻交互；自动确认线以上免人工 |
| **两级提案** | 先概念提名、后 schema 装配的两阶段本体构建策略 |
| **种子本体（Seed Ontology）** | 从标准文档目录+术语表自动生成的初始骨架 |
| **变更检测（Change Detection）** | 两版标准文档的三段式 diff：章节树对齐→段落语义对齐→变更分类 |
| **受影响面（Impact Scope）** | 变更段落→图谱实体→决策卡的反向传播集合（索引查询，非图遍历） |
| **资产（Asset）** | 摄取后的文档单元：编号+模态+权威等级+版本血缘。任务1"资产标识"的落点 |
| **解析体检（Parse Checkup）** | 入库前对文档解析质量的抽样评估分数（T-02） |
| **模板（Skill Template）** | 从成功决策轨迹归纳的参数化 SKILL.md 母版，四变量跨行业复用 |
| **教训（Lesson）** | K7 反馈闭环产出的负样本规则：带问题签名的结构化纠错记录，注入 Skill 的经验槽位 |

## 模型与成本

| 术语 | 定义 |
|---|---|
| **三档模型** | 小/中/大（单价 1:5:20）。分配计划见备忘录 08 分册 §2 |
| **cost-ledger** | 每 run 的 token/延迟/折元台账，周检 20% 预警线 |
| **pass^2 / pass^3** | 每题 3 次独立运行，≥2 / =3 次判对的题占比（τ-bench 口径改造） |
