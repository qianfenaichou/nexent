# ADR-0001：图存储 = PG JSONB + 递归 CTE（graphiti 降为 PoC 备选）

- 状态：Accepted（2026-09-13，决策备忘录 09-A1）
- 语境：图谱存储需支撑 ≤3 跳多跳、bi-temporal、2 万实体级规模，且与 Nexent 上游 PG 共栈。
- 决策：默认 PG JSONB 存储 + 服务层束搜索（逐跳 1-hop CTE）；`GraphStore` 抽象隔离存储 seam；graphiti-on-Kuzu 仅作 PoC 备选（读路径优先切换）。
- 后果：零新运维面、与 12 表同库事务一致；代价是多跳性能上限依赖 PoP P1 验证（p95<1.5s@2万实体）。
- 验证任务：T-07 PoC 三必测点；不过线则切 Kuzu 适配器（~3 人日预算）。

# ADR-0002：本体构建 = 种子引导 + 两级提案（否决自由归纳与模式归纳）

- 状态：Accepted（2026-09-13，决策备忘录 02-K1 §1）
- 决策：方案 (b) 种子本体引导；两级提案（概念提名→schema 装配）；unmappable 实体回流触发增量提案。
- 关键否决记录：纯 LLM 自由归纳——无锚点导致对齐度不可量化、否决成本反噬"半自动"收益；模式归纳——需标注实例，违背低资源前提。两者均可作答辩对比论据。

# ADR-0003：编排位置 = Skill 分层编排 + duty prompt 只写职责

- 状态：Accepted（2026-09-13，决策备忘录 04-K3 §4）
- 决策：入口 Skill（路由+总装）→ 子任务 Skill（retrieval-path/reasoning-path/evidence-assembly）→ 原子 MCP 工具；duty prompt 不写流程。
- 后果：评分维度1"Skill 分层编排"直接兑现；K6 模板归纳有了天然宿主。

# ADR-0004：bi-temporal 自研（不引入 graphiti/mem0 库）

- 状态：Accepted（2026-09-13，备忘录 03-K2 / 07-K7）
- 决策：双时间戳协议与 invalidates 边语义吸收自 Zep/graphiti（arXiv:2501.13956），字段级自研于 kg_entity/kg_relation；K7 教训为结构化规则型，不引入 mem0。
- 后果：依赖矩阵更干净（THIRD_PARTY_NOTICE 少两行）；实现责任在本队（约 +2 人日，可接受）。

# ADR-0005：pass^2 主指标 + 120 题×3 重复的诚实功效口径

- 状态：Accepted（2026-09-13，备忘录 05-K4 §2.1）
- 决策：不做 376 题的统计功效规模；120 题×3 重复 + 95% CI，宣称检出 ≥8pp 而非 5pp。
- 后果：答辩数字经得起追问；judge 偏差控制协议（分离/翻转/抽检）同步落实。

# ADR-0008：弃用优先、不物理删除（本体元素与图谱边一致策略）

- 状态：Accepted（2026-09-13，备忘录 01-K0 §1.1 / 03-K2 §3.2）
- 决策：类/属性/关系一律 DEPRECATE；边 supersede 打戳；split 留双边。删除仅限"从未被引用且提案被否决"。
