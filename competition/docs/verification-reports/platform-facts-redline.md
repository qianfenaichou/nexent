## 3. 必写格式（对外材料的硬性写法）

1. **版本号**：一律写 **v2.6.0**（2026-09-16 发布，月度发版）。仓库迁移文件名 `v2.5.x_kw_*` / `v2.5.5_kw_*` 是历史事实**保留不改**，但仅限仓库内部语境，对外叙述用 v2.6.0。
2. **评估**：模块名写"**智能体评估**"；评测器写"**LLM 判定 / Code 判定**"；Code 判定签名**逐字**为 `evaluate(query, expected, actual, runtime_events)`（返回 `{score, reason}`——返回结构转引自任务书 C §2.4，06 §1.3 未单列），不得自造参数名。
3. **"可进化"归属**：必须绑定平台三实据之一并注明本项目实现——① Dreaming 记忆整理（官方功能页）；② Agent 版本管理回滚（官方功能页）；③ 智能体评估反馈闭环（官方文档）。赛题的"可进化"由本项目 L4 标准对齐器实现，平台只提供上述三件可引实据。
4. **检索**：写"**向量/混合检索（基于 Elasticsearch）**"；本项目向量相似度走服务层 cosine（与平台一致；平台检索**未见**独立向量数据库组件——基于 06 §1.3"全仓无一处"核验的保守表述，若官方文档另列向量组件以官方为准）。
5. **架构图端口**：凡架构表述中标注 5010/5014/5011+5015/5013/5012 处必须注"**容器内端口，对外暴露以部署配置为准**"（运维台账中的宿主端口映射记录豁免；append-only 不改历史）。
6. **记忆**：写"三层记忆（Tenant/User/Agent）+ Dreaming"；可插拔记忆提供方（mem0/aidp）只能写"**代码层支持可插拔记忆提供方**"，不得当官方文档功能引用。
7. **Agent 内核**：写 smolagents；`CoreAgent(CodeAgent)` 可写但须注"代码层确认"（官方文档只写 smolagents）。
8. **Skill**：可写全链——SKILL.md + frontmatter + `<reference>` 渐进披露 + 沙箱 + ZIP 上传 + NL2Skill。
9. **MCP 注册**：写 FastMCP `@mcp.tool()` + SSE URL 界面注册。
