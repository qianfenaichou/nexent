## 二、赛题3 题面（官网原文，逐条抄录）

**题目**：基于华为 ModelEngine Nexent 打造可进化决策智能体

**赛题背景**：医疗、金融、先进制造、政务等行业沉淀海量多模态异构存量数据，大量数据资产缺少统一认知能力，难以支撑复杂跨文档推理、决策追溯；同时行业普遍存在标注稀缺的低资源场景，知识体系更新迭代快，传统固定知识库难以适配动态业务标准。请参赛队伍构建领域资产认知智能体，实现行业数据价值激活与智能化业务编排。

**任务要求（5 条）**：
1. 面向医疗、金融、制造、政务任一或多个行业场景，搭建多模态异构数据资产认知智能体，实现对文本、表格、图文等多元行业数据的统一识别、理解与资产标识。
2. 设计低资源场景下领域知识图谱本体半自动化构建方案，实现本体持续动态更新，并支持与对应行业规范、标准体系对齐。
3. 深度集成 Nexent 的 MCP 协议与 Skills 编排能力，打造"检索-推理"双驱动协同智能体执行流。
4. 挖掘行业沉睡存量数据资产，实现跨文档多跳知识推理、决策链路可溯源；同时提炼通用业务逻辑，沉淀可复用、可快速部署的 Skill 工作流模板。
5. 智能体基于 Nexent 平台可运行。

**分享要求**：入围中国总决赛的作品需开源至开源社区（GitCode 或 GitHub）。
**资源**：可自行下载 Nexent 本地开发（github.com/ModelEngine-Group/nexent / gitcode.com/ModelEngine/nexent）；中国总决赛每队提供一卡华为云算力（代金券购买，供 MCP 等自研工具开发调用）。

> ✅ 与 `00-索引与状态.md` §三「赛题对标矩阵」的 5 条逐字一致，无偏差。

## 三、赛题3 参赛材料要求（初赛 = 我们的当前目标）

**需提交材料**（官网原文）：
1. 提交**开发设计文档 Word**，需包含项目概述、整体方案设计、知识图谱构建方案、智能体构建方案、原始数据说明、数据处理说明等；
2. **Nexent 平台上智能体整体设计思路及详细说明**，包含 Agent 配置的完整细节描述，例如模型信息、工具信息、知识库信息、调用关系图、调试迭代经验、示例问答截图等等，同时附上需要同步提交的 json 文件、知识库和 MCP 等文件的说明。

**评审规则（技术评分 100%）**：
- (25%) 智能体编排与 MCP/Skill 深度集成：深度理解 Nexent MCP 协议核心机制，Skill 分层编排逻辑清晰，可完整搭建检索-推理双驱动协同执行流架构，模块解耦性、扩展性强，适配多行业场景迭代需求；
- (25%) 资产激活的"业务价值"验证：精准聚焦医疗、金融、制造、政务真实行业痛点，明确企业沉睡数据资产激活路径，跨文档推理、决策溯源的业务应用场景清晰，价值落地逻辑闭环；
- (25%) 算法创新性：针对低资源领域场景提出差异化、原创性算法优化方案，**半自动化本体构建效率优势明显**；
- (25%) 系统交互体验与能力沉淀：系统整体架构完整，交互设计贴合用户使用需求，操作逻辑清晰，明确规划可复用 Skill 工作流模板沉淀方案，具备通用推广价值。

**中国总决赛**（晋级后才需要）：材料同上 + 答辩 PPT（项目设计介绍、关键代码解读、知识库扩展、自定义工具开发（可选）、数据处理）。评分：技术 60%（四维各 15%）+ 答辩 40%（材料完整 20% + 问答 20%）。**附加分（10 分）**：①多行业模板轻量化迁移适配验证 ②真实脱敏行业数据集开展效果评测。（与 `00-索引与状态.md` §六 一致。）

## 四、参赛须知要点（官网原文摘录）

1. 参赛对象为高校在校学生（本科/研究生/博士）；每队 **3 名学生 + 1 名指导教师**，同一高校。
2. 报名截止后不得更换指导教师和参赛队员；各赛道报名互斥。
3. 创新赛为报名选拔制，**未采用赛题要求的华为技术的队伍不符合参赛资格**。
4. 截止日期前未按要求提交材料视为自动弃赛；**材料经复核无法复现答辩展示效果的队伍取消晋级/获奖资格**。
5. 知识产权归参赛者；组委会享有复制/发行/展览/传播等权利。

> ⚠️ 第 4 条把「复现」提到资格级：`reproduce-README.md` 的可复现性是硬约束，初赛材料里凡声称的效果必须可复现。
