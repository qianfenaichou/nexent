## 3. 运行时语义等价（区间谓词 ≡ 布尔谓词，全表）
SELECT count(*) FROM kg_relation_t WHERE tstzrange(...) @> now()            => 118400
SELECT count(*) FROM kg_relation_t WHERE (valid_at<=now()) AND (invalid_at IS NULL OR invalid_at>now()) => 118400
两者相等（且退化行=0），证明 valid_range_contains 与 valid_now 在真实 PG 上返回完全一致的行集。

## 4. 重要如实补充（不伪造、不遗漏）
当查询同时带 tenant_id 等值（应用真实用法）时，组合索引 ix_kr_hop_rev_cover
（tenant_id 前缀）被优先选中，区间谓词退化为「Filter」而非 Index Cond——这同样是
正确且更优的访问路径；range 与 bool 两种语义在该路径下仍返回相同行集（见 §3）。
=> GiST 区间索引在「区间谓词独立作为访问路径」时被规划器选用（§2），与组合索引不冲突。
本证据弥补 T4 receipt 中标注 insufficient_data 的那一项。
